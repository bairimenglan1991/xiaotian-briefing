1. 美伊冲突再燃，霍尔木兹航运风险升高

FT全文称特朗普表示美国将对伊朗“强硬打击”，WSJ同时报道水雷战正在妨碍美国取得霍尔木兹海峡控制权。可以确认军事与航运风险上升，但尚无证据表明海峡已全面封锁或全球原油供应出现同等规模的实际中断。

来源：FT全文

2. 日本10年期国债收益率触及3%，创1996年以来新高

Bloomberg会员全文显示，日本10年期国债收益率一度上升6个基点至3%，为1996年以来最高，约为一年前同期的两倍。该变化反映日本利率正常化加速，可能提高政府、企业和家庭融资成本，并通过日元套息交易影响全球资本流动。

来源：Bloomberg全文

3. Shein香港上市首日一度跌10%，估值较峰值缩水约四分之三

WSJ会员全文显示，Shein以每股48.56港元定价，募资约17.3亿美元；上市首日一度跌至43.72港元，隐含市值约240亿美元。监管阻力、美国收入下降、竞争加剧和增速放缓共同压低估值，说明跨境电商已从流量扩张转向合规与盈利质量竞争。

来源：WSJ全文

4. 特朗普为数据中心扩张辩护，AI电力与社区阻力进入政治议程

FT全文报道，特朗普称反对数据中心的人会让美国“落后和贫穷”，显示AI基础设施已从企业资本开支问题升级为政治议题。总统表态可以影响行政部门和舆论，但不等于地方许可、电网接入、土地审批和电价争议已经解决。

来源：FT全文

5. FTC披露Amazon广告定价机制，平台监管压力延伸至广告市场

WSJ报道，美国联邦贸易委员会披露Amazon一套未公开广告定价系统的运作方式。该事件显示平台监管不只关注商品和佣金，也开始审视广告竞价、信息透明度与市场支配力；但监管指控并不等同于法院已认定违法。

来源：WSJ摘要

6. 中国就台湾参与太平洋岛国会议提出抗议

Bloomberg报道，中国在太平洋岛国领导人会议期间对台湾参与提出抗议。事件反映台湾议题继续向区域外交和发展合作场域外溢，但外交抗议不等同于贸易、投资或安全政策已经改变；后续需观察主办方规则、成员国立场与具体反制。

来源：Bloomberg摘要

7. Airbus选择曼谷设立数字业务总部

Bangkok Post报道，Airbus选择曼谷作为数字业务总部。该决定有利于泰国承接航空数字化、工程服务和高技能岗位，但“总部落地”本身不能证明大规模就业和本地供应链订单已经形成；应继续观察投资额、团队规模、采购和人才培养计划。

来源：Bangkok Post

8. 特朗普支持联邦影视制作税收激励，行业组织与民主党议员响应

Variety与Screen Daily报道，特朗普支持建立美国联邦影视制作激励，电影协会和一名民主党参议员表示支持。跨党派响应提高讨论热度，但税收激励需要国会立法、财政安排和执行规则，当前不能视为已经生效的产业政策。

来源：Variety / Screen Daily

CAUSAL CHAINS

三条关键因果链

1. 日本收益率与全球资本流动

日本长期收益率上升 → 日元资产相对吸引力提高 → 海外套息头寸回报下降 → 可能触发资金回流与全球期限溢价上升。

机制：融资币成本与跨境资产收益差变化。假设：日元升值、对冲成本提高且日本央行容忍收益率上行。失败条件：日元继续弱、央行压低收益率或海外风险资产回报更高。置信度：首两节点中高；大规模平仓中低，后续仅为条件分支。

2. 霍尔木兹风险与通胀

军事与水雷风险 → 航运保险和运费上升 → 若油轮流量下降才形成物理供应收紧 → 油价与通胀预期上升 → 货币宽松空间受限。

机制：风险通过运输、保险、库存和能源成本传导。失败条件：冲突降级、航运维持、替代供应或库存吸收。置信度：风险溢价中高；物理断供低，因此不能作为基准结论。

3. Shein与跨境电商估值

税制与合规压力 + 美国收入放缓 → 增长和利润预期下调 → 公开市场估值下降 → 融资与扩张纪律增强。

机制：监管成本和竞争影响单位经济与现金流。反例：亚洲增长、供应链效率或品牌升级抵消美国下滑。置信度：当前估值与收入压力中高；行业全面外推中低。
